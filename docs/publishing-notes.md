# Publishing Notes

## License decision

Use `CC BY 4.0` for the open textbook. This keeps the adoption path simple for colleges, high schools, workforce programs, and employers.

Keep instructor-facing supplements as separate commercial works. That includes Canvas exports, test banks, slide decks, lab solution keys, rubrics, private instructor notes, and implementation guides.

## Versioning

Use pre-1.0 tags while the book is incomplete:

- `v0.1.0`: Quarto pilot with preface and Chapter 1.
- `v0.2.0` through `v0.9.0`: additional chapter conversion milestones.
- `v1.0.0`: first complete public edition.

After `v1.0.0`, use semantic versioning:

- Patch release: typo, errata, broken link, minor correction.
- Minor release: new section, revised lab, updated examples.
- Major release: substantial course or structure change.

## DOI and cataloging

Use Zenodo after the repository has a complete `v1.0.0` release. Zenodo can mint a concept DOI for the project and version-specific DOIs for tagged releases.
